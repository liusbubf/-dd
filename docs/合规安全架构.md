# 合规安全架构（适用于云手机平台）

> 说明：本项目不提供、测试或推广任何绕过应用安全检测、伪造安卓完整性认证、伪造 TEE/Keymaster 或欺骗 Google Play Integrity 的能力。这类行为会破坏平台合规性，并可能违反安全、反欺诈和服务条款。 
>
> 本文档提供的是一套合法、可验证、适用于合规云真机/自动化测试场景的架构方案，支持隔离、审计、调试和可追溯性，而不以“绕过防护”为目标。

## 1. 设计原则

- 合规为先：遵循各平台的服务条款、隐私要求和安全政策。
- 真实隔离：每个实例都有明确的网络、存储、身份、生命周期隔离。
- 可审计：所有变更、镜像和网络配置都可追踪。
- 可验证：通过白名单、设备清单、签名和完整性校验来确认环境真实与安全。
- 生产兼容：使用真实安全能力，而非伪造或欺骗第三方检测体系。

## 2. 合法增强能力

### 2.1 独立网络与出口 IP
- 支持每个实例独立 egress IP / namespace / veth / policy routing。
- 配置 `network_mode`：`shared`、`exclusive`、`multi-nic`。
- 默认使用显式的代理/网关控制，而不是通过绕过检测来隐藏真实链路。
- DNS 解析和 HTTP(S) 流量都可审计，支持 leak-prevention 规则。

### 2.2 安全镜像与真实环境建模
- 每次实例创建时从受控模板生成镜像，不依赖“硬伪造系统调用结果”。
- 支持在 QA / 演示环境中随机化设备配置，但必须明确标记为测试环境，并保留审计记录。
- 对安全审计场景保留真实 Attestation 的可信路径，而不是伪造官方证书。

### 2.3 图形与输入层的真实性
- 在虚拟化环境中，使用真实的 EGL/OpenGL 兼容层和规范的驱动配置，而不是伪造显卡制造商身份。
- 对 WebGL / Canvas 的兼容性测试采用白名单和参考设备库，而不是“跟风检测”绕过策略。
- 区分“兼容性调优”和“欺骗第三方完整性验证”两件事。

### 2.4 传感器与行为模拟（仅测试场景）
- 允许为自动化测试生成可控的传感器信号和行为轨迹，用于 UI 测试、脚本回放、回归验证。
- 这类数据必须被显式标注为 `test_only`，不能用于隐匿真实设备身份或规避反欺诈检测。
- 如对外部服务提供模拟行为，应遵循平台合规要求，并保留清晰的使用边界。

## 3. 架构建议

### 3.1 运行时分层
1. 控制面（管理平台）
   - 设备生命周期、权限、模板镜像、审计日志、任务调度。
2. 网络面
   - DNAT / SNAT / egress policy / DNS resolver / proxy routing / VPN / traffic controls.
3. 设备面
   - Simulator / Redroid / VM / container runtime；每个实例独立资源池。
4. 安全面
   - 签名校验、镜像完整性、白名单策略、环境标签、审计。
5. 监控面
   - 延迟、网络、设备状态、日志、错误码、告警。

### 3.2 合规检查项
- 任何设备配置都要列入清单：品牌、型号、Android 版本、内核版本、运行时配置。
- 对于与第三方服务集成的场景，必须遵循真实的使用协议和安全要求。
- 所有高风险模板必须保留审批记录和使用时间窗。

## 4. 推荐落地方式

- 真实环境：在受控的虚拟化平台中部署实例，保留真实运行时标识与签名。
- 测试环境：使用受控随机化模板，专门服务于回归、脚本、界面和日志测试。
- 安全环境：在具备审计和白名单控制的基础设施上运行，确保可追溯。

## 5. 可选增强项（合规）

- 设备模板库：不同 QA / 测试场景的设备模型与分辨率模板。
- 代理治理：按用户、租户和设备组配置允许的出口 IP 与代理策略。
- 监控与告警：CPU / GPU / memory / latency / packet loss。
- 一键还原：基于镜像快照或增量层进行快速回滚和恢复。
- 日志审计：记录实例创建、变更、销毁和网络策略变更。

## 6. 结论

本项目适合扩展为“合规、审计、可控、可验证”的云手机平台，而不是绕过公开安全检测、伪造完整性验证、或欺骗 Google Play Integrity。 

如果你的目标是：
- 真实云手机运营
- 自动化测试和回归验证
- 可追溯的设备管理
- 受控网络环境
- 合法的安全评估与审计

那么上面的架构是合适的落地路径。
