# 已知限制与待办

> 本文是**能力边界声明**。本仓库是「可运行的演示/交付底座」，不是生产级系统。
> 交付、投标或对外宣传时，请不要把下列「演示级」能力描述为已生产可用。
> 依据：`docs/验收报告.md` 的「待实现」清单 + 代码现状复核（2026-11）。

## 一、演示级能力（能演示，但不能按生产标准承诺）

| 能力 | 现状 | 说明 |
|---|---|---|
| iOS 外观 | **皮肤级**：Lawnchair 图标包 + 壁纸 + 网格/Dock/页面圆点；另有 7 屏 SVG 矢量预览（`backend/app/preview.py`） | 非系统级 ROM，SystemUI/控制中心/锁屏/设置未复刻 |
| 投屏 | 截图轮询 1–12 fps（~400ms 延迟）为主；ws-scrcpy H.264 为可选链路 | ws-scrcpy 未鉴权、未同源反代 |
| 设备规模 | 实测：8GB VM ≈ 10 台 Redroid 实例 | 500 台仅 k8s 预研，未上真集群 |
| 渲染 | VM 内 SwiftShader 软件渲染 | 无硬件 GPU 加速；`gpu_mode=host` 需 Intel/AMD 裸机 |
| App 客户端 | Kotlin/Compose 骨架，4 屏 | 未 Gradle 出包，无 APK |
| PC 客户端 | Electron 壳加载网页控制台 | 无离线安装包 |
| 告警 | 5 条静态规则，**请求时实时计算** | 不落库、无通知通道、无告警收敛 |
| 审计 | 写操作调用 `record_audit` | 覆盖主要写接口，但不保证全量 |

## 二、待办清单（按优先级）

### P0（安全 / 正确性）

- [ ] **ws-scrcpy 同源反代 + 统一鉴权**：当前 iframe 直连 `:8100`，绕过 JWT；应改为 nginx 反代 `/scrcpy/` 并校验 token。
- [ ] **投屏链路收敛**：去掉「截图轮询 / ws-scrcpy」双链路冗余，保留一条并统一错误语义。
- [ ] **数据库迁移**：`database.py` 目前是 `create_all` + `ensure_schema()`（幂等补列/补索引），生产仍应引入 Alembic；本轮未引入半成品骨架。
- [x] **`/api/users/me/password` 路由级依赖叠加**（2026-11-04 已修）：自助端点拆到 `users.me_router`，任何已登录用户可改自己的口令，改不了他人；`backend/tests/test_rbac.py` 有回归用例。
- [x] **CORS 默认全开**（2026-11-04 已修）：默认只放行 `localhost:5173/4173`，生产用 `CLOUD_CORS_ORIGINS` 显式配置。

### P1（规模化 / 稳定性）

- [ ] **前端 ESLint**：`frontend/package.json` 目前只有 `dev/build/preview`，未引入 ESLint；引入需新增 eslint + eslint-plugin-vue 依赖并改写锁文件，本轮先记为待办。
- [ ] **Alembic 最小骨架**：需引入 alembic.ini + versions/ 并改写启动流程，本轮保留 `ensure_schema()` 幂等方案，不交半成品。
- [ ] **preview 帧缓存 TTL**：`preview.py` 的帧缓存/订阅清理未做上限与 TTL，需单独一批验证。
- [ ] **async 阻塞调用**：docker SDK / subprocess adb / `time.sleep` 仍可能阻塞事件循环，优先改截图与控制高频路径。
- [ ] **500 台 k8s 落地**：`deploy/k8s/` 为设计稿，未在真实集群验证；容量、调度、HPA 策略需实测回填。
- [ ] **稳定性压测**：仅做过密度实测，缺 2h+/72h 持续压测与故障注入。
- [ ] **cells/实例编排**：Redroid 实例与节点亲和、数据盘回收、批量重建仍需设计。
- [ ] **告警持久化与通知**：落库 + 去重 + 邮件/IM 通道。

### P2（功能 / 体验）

- [ ] **云盘用户级隔离**（2026-11-05 新增）：当前云盘为共享空间（`uploaded_by` 仅记录上传人），未做「我的文件 / 公共文件」双层目录与配额隔离。
- [ ] **云盘下发任务持久化**（2026-11-05 新增）：`routers/cloud_disk.py` 的下发任务存在内存（TTL 1h），进程重启丢失；生产应落库并支持断点续跑。
- [ ] **IP 资源池与 pick_proxy 统一**（2026-11-05 新增）：当前显式绑定 `ip_id` 并写指纹，未接入环境变量随机代理池；两套选路需在 P1 收敛。
- [ ] **到期自动回收**（2026-11-05 新增）：仅前端提醒 + `/devices/expiring` 查询，未做到期自动停机/回收。

- [ ] **系统级 iOS ROM**：AOSP SystemUI fork，复刻控制中心/锁屏/设置（工作量最大）。
- [ ] **硬件 GPU 加速**：Intel/AMD 裸机 Mesa `/dev/dri` 路径验证（NVIDIA 闭源驱动不支持）。
- [ ] **传感器模拟（CP-008）**：GPS/陀螺仪注入，redroid 注入路径待验证。
- [ ] **App 出包**：补 Gradle wrapper + 签名，产出 APK 并三端联调录屏。
- [ ] **真机 iOS 图标包 APK**：需 Android SDK 工具链（当前阻塞）。
- [ ] **文件互传增强（PC-104）**：大文件、断点续传、进度条。

### 合规 / 授权（非代码项）

- [ ] **ARM 转译授权**：libndk/libhoudini 为专有库，商用需书面确认（当前用 64only 原生 arm，未依赖转译）。
- [ ] **业务合规**：目标站点账号合规、反作弊对抗、数据留存策略由使用方承担。

## 三、明确不做（避免误解）

- 不提供绕过目标站点风控/检测的能力（见 `docs/合规安全架构.md`）。
- 不修改 IMEI/serial 等硬件级标识（`physical` 后端明确只做 adb 层可控项）。
