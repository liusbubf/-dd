## 四、未完成项与风险

### 未完成（如实）

1. **设备分享 / 转移**：设备没有归属人字段，做不了越权校验；需要先定租户/归属模型（见路线图）。
2. **清理屏锁**：后端没有锁屏抽象；未加空按钮。最快路径是给 `DeviceBackend` 加 `unlock()`（不改现有结构）。
3. **重置设备 V3**：无 V3 概念与任务实体，不能假装实现。
4. **批量任务历史**：云盘下发已落库，但 `/batch/*` 仍只有 WS 进度、无历史表；路线图 V1 的「推送进度页」需要补 `batch_jobs`。
5. **浏览器实测**：本轮只做接口测试 + 构建，未启动浏览器验证视觉与交互（缩略图懒加载、云盘历史弹窗）。

### 风险

- **云盘老数据**：`owner_id` 为空的历史文件按 `uploaded_by == username` 兜底；若两个账号同名会误判，账号名本身由系统唯一约束控制，风险低但需知悉。
- **下发任务中断粒度**：进度按「每台设备」落库；进程在一台设备传输中途退出时，该设备项会保留 `pending`，任务整体标 `interrupted`，不会重复执行已完成项。
- **截图缓存被绕过**：`fresh=true` 对 viewer 开放，可强制高频截图；如需严格限流应在网关或接口层加频率限制（本轮未加）。
- **到期回收**：默认关闭；开启后停机失败会保留到期时间并重试，可能造成每轮重复告警日志；回收后清空 `expires_at`，不会二次回收。
- **ruff/构建**：ruff 全绿；构建仅有既有的 chunk 体积警告，非本轮引入。

## 五、核实后与文档判定不一致之处

1. `docs/功能对照与补齐方案.md` 写「设备模型无到期字段」——已成为历史；`expires_at/ip_id` 在 P0 已加，本轮无需再加。
2. 文档写「控制菜单后端已有 restart/screenshot」——属实；但**清理屏锁、分享、转移、重置 V3 确实没有**，不能只补前端按钮。
3. 文档写「移动分组在 Groups 页」——后端接口一直可用，只是设备行没有入口；本轮补的是入口，不是新接口。
4. 文档写「挂载 IP 复用 `pick_proxy`」——原 `pick_proxy` 只是代理池随机选择，**不是显式绑定**；本轮才把两套逻辑收敛到 `ip_routing`。
5. 云盘「我的文件 / 公共文件」双层：原本只有全局共享空间；本轮才补 `owner_id/is_public`，普通用户默认看不到别人的文件。
