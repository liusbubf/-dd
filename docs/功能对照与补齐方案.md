## 1. 结论：视频里是什么产品，一共有哪些能力

### 1.1 产品定性

视频录的是 **Yunmomo（云沫沫）云手机 SaaS 管理后台**（`https://cloud.yunmomo.com/#/dashboard`），一个面向个人/工作室的**租用型云手机控制台**，不是私有化交付平台。

三个特征非常明确：

1. **租用与计费是主线**：顶部常驻 `总积分 / 储值 / 加速 / 充值`，左侧一级菜单就有 `卡密中心 / 免费领取 / 购买·续费`，还有独立的 `代理中心`（邀请码、返利比例、下线团队）。
2. **一台机器一个浮窗**：设备页双击/点卡片弹出独立投屏浮窗（标题就是云机号 `4`），浮窗自带尺寸滑杆、右侧功能竖栏、Android 导航栏，是"能干活"的作业界面。
3. **云盘是分发中枢**：文件不落在单机上，而是先上云盘（5GB 共享空间 + 30 个公共安装包），再「一机一传 / 传输至云机」批量下发——这是同类产品做规模化的标准打法。

### 1.3 与现有项目的定位差异（关键判断）

| | 竞品（视频） | 现有仓库 |
|---|---|---|
| 形态 | 公有云租用 SaaS | 私有化 X86 云手机群控底座（redroid + ws-scrcpy） |
| 强项 | 计费闭环、云盘分发、多标签工作台、投屏操作细节 | 设备指纹/一机一码、批量群控、脚本录制回放、任务调度、告警、报表、RBAC、审计、快照/一键新机 |

> 也就是说：**要补的是"商用 SaaS 的外壳与分发链路"，不是核心编排能力**——核心编排这块现有代码反而更完整。

### 3.1 设备列表（我的云机）
- **入口**：左侧「设备管理 → 我的云机」；顶部工作台页签「我的云机」。
- **左侧树**：`未分组 (0)`、`他人分享 (2)`（他人分享的设备来源）。

- **反馈**：点击卡片选中（勾选圆点）、双击打开浮窗；到期设备以红框/红字标识。

### 3.3 单机投屏浮窗
- **入口**：列表卡片双击 / 点"打开"；也可"页面"方式内嵌。
- **顶部**：标题=云机号；`点输入框后打字` chip；键盘、刷新、最小化/还原、关闭；`自动刷新` 开关；渲染设置（旧版/新版）。
- **尺寸**：滑杆（示例 720），实时缩放画面；相邻两个绿色小按钮（预设/复位，**待确认**具体语义）。
- **右侧竖栏**（9 个）：键盘、设备信息/电话、麦克风、音量、文本/备注、显示、网络/ADB、上传、文件夹；悬浮"设备控制"与"上传文件 / 云盘推送"二级浮层。
- **设备控制菜单**：开机 / 关机 / 重启 / 重置云机 / 重置设备V3 / 分享（取消分享）/ 转移设备 / 移动分组 / 清理屏锁重启生效 / 高清截图 / 改机。
- **底部**：Android 返回/主页/任务导航条，任务切换器（Recents）。
- **反馈**：连接中 loading、加载后直出真实画面；操作后画面即时变化。

### 3.4 群控与分发
- 批量操作 + 已选计数 + 推送进度 + 分身切换（视频只展示入口）。
- 云盘「一机一传」「传输至云机」「一机一传进度」「传输列表」：把云盘文件批量下发到多台云机，并独立展示进度。

### 3.5 云盘（文件中心）
- **入口**：左侧「云盘」；首页快捷入口「云盘」。
- **分区**：我的文件 / 公共文件。
- **分类**：全部 / 安装包 / 图片 / 视频 / 文件 / 文档 / 音频（带计数）。
- **文件操作**：上传文件至云盘、全选、刷新、删除、重命名、默认排序（排序下拉）、双击预览（图片原图 / 音视频直接播放）、单击选中。
- **分发**：一机一传、传输至云机、一机一传进度、传输列表。
- **容量**：已用/总量（0 B / 5.00 GB）、百分比、扩容云盘。
- **规则**：超过 30 天未登录自动清空。

### 3.6 分组与网络
- **云机分组**：设备按分组管理（左侧树 + 页签）。
- **VPC 网络管理**：IP 资源池 CRUD。
  - 字段：IP、端口、用户名、密码、测试结果、到期时间、备注、分组。
  - 操作：新建、修改、删除、批量新增、分组管理；筛选 IP/备注/分组 + 查询/重置。
  - 反馈：空态"暂无数据"；`测试结果` 列承载可用性校验结论。

### 3.7 计费与商业化
- **卡密兑换**：名称、使用次数（兑换次数上限）；新建/批量导入/修改/删除。
- **云机续费**：按云号/名称筛选、全选/清空、续费天数（默认 30）、支付方式（微信支付）、积分抵扣、自动试算合计、确认续费。
- **卡密续费**：勾选云机 → 续费 → 验证卡密 → 确认；列表含云号、分组、过期时间、旧到过期。
- **积分/充值**：总积分、储值、加速、充值入口、积分记录、修改密码。
- **代理中心**：等级（青铜）、邀请码与两条邀请链接、返利与消费积分、我的团队/返利明细/我的积分/等级规则、升级推广员（门槛 10 人、25% 起）。
- **免费领取 / 我的团队 / 下载中心 / 使用指引**。

### 3.8 账号与偏好
- **登录**：账号 + 密码 + 图形验证码；去注册 / 忘记密码；明暗主题；多端下载（HS/App/客户端）；HTTP/2 徽标；登录按钮 loading 文案「正在建立云端连接…」；成功后 toast 带**上次登录 IP 与时间**。
- **偏好浮层**：云机界面（ip显示）、智控布局（自动复制）、快捷操作（表格范围选择）。

### 8.2 与文档原始判定的偏差（实现前核实结果）

1. 文档称「设备模型无到期/IP 资源字段」——属实，本轮已新增 `expires_at` 与 `ip_id`（非复用旧字段）。
2. 文档称控制菜单「后端已有 restart/screenshot」——属实；但开关机接口是 `start/stop`，且 screenshot 对 viewer 也可读，无需 operator。
3. 「挂载 IP 复用 `pick_proxy`」——现有 `pick_proxy` 是环境变量代理池的随机挑选，并非显式绑定；本轮改为显式绑定 `ip_id` 并写入指纹 `network.exit_ip/proxy`，未强制复用随机逻辑（避免行为不可预期）。
4. 文档提到「云盘我的文件/公共文件」双层——现有代码无用户级目录概念，本轮先做共享空间（`uploaded_by` 记录上传人），用户级隔离记为 P1。
